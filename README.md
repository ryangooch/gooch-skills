# gooch-skills
a repo for my Agent Skills

## my skills

* use-uv -- makes it so that agents use `uv` for python commands
* reduce-llm-writing-patterns -- helps LLMs produce text that does not rely so heavily on
    various AI-writing patterns, like the Rule of Three and negative parallelisms

## borrowed skills
all props to the original creators of these; I have minimally edited/updated these to fit my
needs.

* grill-me -- Matt Pocock's earlier formulation of this skill, which I find more helpful in a
    vacuum than his more recent updates, which follows his workflow. check out his stuff 
    though, it's pretty great (https://github.com/mattpocock/skills)
